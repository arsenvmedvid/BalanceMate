# 🥗 BalanceMate — AI-помічник для підрахунку КБЖВ

**BalanceMate** — це розумний Telegram-бот, створений для тих, хто стежить за своїм харчуванням. Він допомагає розраховувати персональну добову норму та вести щоденник харчування, використовуючи локальну базу страв та штучний інтелект.

## 👥 Цільова аудиторія проєкту

Бот **BalanceMate** розроблений для широкого кола користувачів, які прагнуть свідомого ставлення до свого способу життя:

* **Спортсмени та фітнес-ентузіасти**: люди, яким важливо контролювати кількість білків для росту м'язів або калорій для підтримки форми.
* **Люди на етапі зниження ваги**: ті, хто веде підрахунок КБЖВ для досягнення дефіциту калорій без стресу.
* **Початківці у сфері ЗСЖ**: користувачі, які тільки вчаться розуміти поживну цінність страв і потребують швидких підказок (зокрема через AI).
* **Зайняті люди**: завдяки можливості вводити список продуктів одним рядком через кому або "та", бот економить час на щоденному заповненні щоденника.
* **Студенти та розробники**: проєкт також слугує прикладом інтеграції Telegram API з сучасними LLM-моделями (Llama 3) для вирішення побутових задач.

## ✨ Основні можливості

* **📊 Персональні норми**: Автоматичний розрахунок КБЖВ за формулою Міффліна-Сан Жеора.
* **📝 Розумний щоденник**: Можна вводити продукти списком через кому, "+" або слова "та"/"і" (наприклад: `гречка 200, філе 150 та огірок 100`).
* **🔍 Точний пошук**: Алгоритм пріоритезує назву продукту (підмет), тому не плутає "гречку" з "кіноа" лише через схожі прикметники.
* **🔘 Вибір із варіантів**: Якщо в базі кілька схожих страв, бот виведе кнопки для уточнення (наприклад: `картопля фрі` чи `картопля пюре`).
* **🌐 AI-інтеграція (Groq)**: Якщо продукту немає в базі, бот миттєво дізнається його КБЖВ через ШІ (Llama 3).
* **🎨 Гарний дизайн**: Звіти оформлені емодзі для наочності (🔥 ккал, 🥩 Б, 🥑 Ж, 🍞 В).

## 🛠 Технологічний стек

* **Python 3.x**
* **python-telegram-bot** — для інтерфейсу.
* **Groq API** — для розпізнавання невідомих страв.
* **python-dotenv** — для безпеки ключів.

## 🚀 Швидкий старт

1. **Клонуйте проєкт**:
   ```bash
    git clone [https://github.com/arsenvmedvid/BalanceMate.git](https://github.com/arsenvmedvid/BalanceMate.git)
    cd BalanceMate

2. **Встановіть усі бібліотеки**:
    pip install python-telegram-bot groq python-dotenv

3. **Налаштуйте ключі**:
    Створіть файл .env у папці проєкту та впишіть:
        TELEGRAM_TOKEN=ваш_токен_від_botfather
        GROQ_API_KEY=ваш_api_ключ_від_groq

4. **Запустіть бота**:
    py bot.py or python bot.py
